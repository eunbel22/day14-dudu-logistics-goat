두두택배 접수 화면 - 한 장 완성

파일: single-page.html
브라우저로 열면 바로 실행됩니다. 설치할 것도, 인터넷도 필요 없습니다.

[이 화면은]
단계가 없습니다. 한 화면에 전부 있고, 값을 넣는 즉시 옆에서 계산 과정이 펼쳐집니다.
왜 이 요금이 나왔는지 눈으로 따라갈 수 있습니다.

[오늘 할 일]
1. 화면을 열고 처음부터 끝까지 한 번 접수해 봅니다.
2. 어제 내가 쓴 정책서를 펼칩니다.
3. 정책서에 적은 규칙이 이 화면에서 실제로 도는지 하나씩 확인합니다.
4. 안 되는 것을 하나 골라 고칩니다.

[확인할 때 쓰는 값 - 규정대로면 이렇게 나와야 합니다]
  이불   3.0kg  60x40x50 cm  일반  ->  대형    9,000원
  책    12.0kg  30x20x20 cm  일반  ->  중형    6,000원
  화장품  1.5kg  20x15x10 cm  일반  ->  극소형  3,500원
  운동화  2.0kg  35x25x20 cm  일반  ->  소형    4,000원
  쌀     8.0kg  30x20x20 cm  일반  ->  중형    6,000원

[알아두기]
- 접수 지점과 배송 권역은 직접 입력합니다. 목록에 없는 값을 적으면 기본값으로 처리됩니다.
- 계산 규칙은 네 화면이 전부 같습니다. 화면 구성만 다릅니다.
- 정본은 02_접수규정.md 입니다. 화면과 규정이 다르면 규정이 맞습니다.
