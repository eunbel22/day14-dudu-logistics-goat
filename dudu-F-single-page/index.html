1. 접수 지점을 선택하세요

운송장 앞 2자리 지점 코드에 쓰입니다 (규정 §9).

2. 보내는 분 / 받는 분

이름은 목록이 없어 직접 입력해야 합니다.

3. 물품명을 선택하세요

자주 접수되는 품목입니다. 목록에 없으면 직접 입력을 누르세요.

자주 쓰는 물품

4. 크기와 무게

아래 프리셋을 누르면 값이 자동으로 채워집니다. 직접 조정해도 됩니다.

규격 프리셋 (등급 기준 중간값)
가로
세로

무게(kg)

세 변의 합이 160cm 이하, 무게 25kg 이하까지 접수됩니다. 초과하면 대형화물 전문 창구(1600-5678)로 안내됩니다.

5. 도착 지역을 선택하세요

제주는 제주 권역, 5개 도서는 도서산간, 나머지는 전부 일반입니다 (거제·진주 포함).

권역 (자동으로 판정됨)
🟦 일반 권역
🟩 제주 권역
🟨 도서산간 권역

표기 갈림(서울/서울시 등)을 막기 위해 직접 타이핑은 받지 않습니다.

6. 입력 내용 확인

오른쪽 계산 과정을 확인하고 접수를 완료하세요.

요금표 - 4등급 x 3권역 12종 전부 (규정 §3)

등급 기준(세변합 / 무게) 일반 제주 도서산간

계산 과정 (규정 그대로, 숫자를 대입해서 보여줍니다)

무게・가로・세로・높이를 모두 입력하면 계산 과정이 여기 순서대로 표시됩니다.
